# Kinokompass – Web-App

Filme & Serien bewerten, persönliche Vorschläge, Trends bei deinen Streamingdiensten, Freunde.

**Öffnen:** https://kinokompass-crew.github.io – am iPhone in Safari: *Teilen → Zum Home-Bildschirm*.

Hier liegt nur der App-Code. Bewertungen und Schlüssel bleiben auf deinem Gerät bzw. in deinem eigenen, privaten Speicher.
Film- und Bilddaten: TMDB (diese App nutzt die TMDB-API, ist aber weder von TMDB unterstützt noch zertifiziert). Streaming-Angaben: JustWatch.
